# Word-Game-Lists
Lists of words from various word games!

While working on my own project involving word lists from many popular word games, I struggled to find a lot of those lists. For many, I literally copied each individual word into a spreadsheet as I went through the game's physical cards.

I'm hoping this little repo will ease the process for others working on similar projects.

If you're interested, the project in question was Word Gamer PLUS: https://zacdevdude.itch.io/word-gamer-plus
